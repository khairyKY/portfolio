Welcome 👋

This interactive guide covers CSE 429 Computer Vision and Pattern Recognition so far: how digital images are made, pixels and their neighbours, interpolation, image operations, intensity transformations and histogram equalization. It follows Gonzalez & Woods' Digital Image Processing (3rd ed.), the lecture slides and Sheets 1–3. Where a slide has a mistake, the guide says so and gives the correct version. Navigate through the modes below:

  • 📖 Tutorial Mode: each step goes idea → worked example → why → quick check, with tap-to-trace tables and explorers for paths, zooming and equalization.
  • 🎴 Flash Cards: definitions, formulas and the worked answers you should know cold.
  • 🎯 Professor's Focus: exam-style theory answers and every sheet problem worked in full: Part 1 (image fundamentals) and Part 2 (enhancement).
  • ⚡ Practice Quiz: exam-style MCQs from the lectures and all three sheets.

💡 Short on time? Do Tutorials 4, 7 and 8: they hold every numerical problem. Press Ctrl+K to search, and open the 📋 Cheat Sheet (bottom-right) for every formula.

📋 Exam Reference Sheet

Digital Images

  • Digital image: f(x, y) with x, y and f discrete. Origin top-left, x = row, y = column.
  • Sampling digitizes coordinates; quantization digitizes amplitude.
  • Levels: L = 2k (1→2, 4→16, 7→128, 8→256, 9→512, 16→65,536).
  • Size: rows × cols × channels × k bits; ÷ 8 = bytes; ÷ 220 = MB.
  • Transmission: packet = start + data + stop bits; time = total bits ÷ baud.
  • Dynamic range = max measurable / min detectable; contrast = highest − lowest.
  • PET: positron + electron → two gamma rays (detected). CT: X-rays.

Python

  • Shape (height, width, channels); uint8 0–255 wraps mod 256; float 0–1.
  • img_as_float float64 · img_as_ubyte uint8 · img_as_uint uint16 · img_as_int int16.
  • 2-D arrays: plt.imshow(img, 'gray'); histogram: plt.hist(img.ravel(), 256).

Neighbours & Adjacency (values in V)

  • N4: (x±1, y), (x, y±1). ND: (x±1, y±1). N8 = N4 ∪ ND.
  • 4-adj: q ∈ N4(p). 8-adj: q ∈ N8(p).
  • m-adj: q ∈ N4(p), or q ∈ ND(p) and N4(p) ∩ N4(q) has no V pixels (check the two corners).
  • Path length = steps = pixels − 1. m and 8 give the same regions.

Distances

  • De = √((x−s)² + (y−t)²) (disc)
  • D4 = |x−s| + |y−t| (diamond; D4 ≤ 2 = 13 pixels)
  • D8 = max(|x−s|, |y−t|) (square; D8 ≤ 2 = 25 pixels)
  • D8 ≤ De ≤ D4.

Interpolation

  • Nearest: output (i, j) ← input (⌊i·R/R′⌋, ⌊j·C/C′⌋). Shrink = delete rows/cols.
  • Bilinear: v = ax + by + cxy + d from 4 neighbours = lerp along edges, then between them.
  • Bicubic: Σ aijxiyj, i, j = 0..3: 16 neighbours.

Operations

  • Image × image = array (element-wise) product.
  • Linear: H[a f₁ + b f₂] = a H[f₁] + b H[f₂]. Σ linear, max not.
  • Sum 0–510, difference −255–255: clip, or scale 255·(f − min)/max(f − min).
  • ROI: multiply by a 1/0 mask. A − B = A ∩ Bᶜ; A ∪ B = A, B or both.
  • Point / local / global: one pixel / neighbourhood / whole image.

s = T(r), r in 0 … L − 1

  • Negative: s = L − 1 − r
  • Log: s = c·log(1 + r), c = 255/ln(1 + rmax) ≈ 45.99. Use float, not uint8.
  • Gamma: s = c·rγ on 0–1. γ < 1 brighter, γ > 1 darker.
  • Stretch: (I − Min)(NewMax − NewMin)/(Max − Min) + NewMin, round to nearest.
  • Piecewise: r₁ = s₁, r₂ = s₂ identity; r₁ = r₂, s₁ = 0, s₂ = L − 1 threshold.
  • Slicing: [A, B] → 255; rest → 0 (binary) or unchanged. Say whether the ends count.
  • Bit plane k: ⌊r / 2k−1⌋ mod 2; plane 8 = MSB.

Histogram

  • h(rk) = nk, p(rk) = nk/MN.
  • Dark → left, bright → right, low contrast → narrow middle.

Equalization recipe

  • nk → pk → running total Σp → × (L − 1) → round = sk → replace each rk by sk.
  • Lec 4 4 × 8: s = 1, 3, 4, 5, 7 (slide's "7(0.357) = 2" is wrong).
  • Ex 3.5: 0→1, 1→3, 2→5, 3→6, 4→6, 5→7, 6→7, 7→7.
  • Matching: s = T(r), G(z) = (L − 1)Σpz, z = closest G to s.
  • Stats: m = Σ r p(r), σ² = Σ (r − m)² p(r).
